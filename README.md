# Dice Rolling Simulator

A simple Python console application that simulates rolling two six-sided dice. The program continues to roll and generate two random dice results until the user chooses to exit.

## Features

- Simulates rolling two standard 6-sided dice ($1$ to $6$).
- Simple interactive terminal interface (`y`/`Y` to roll, `n`/`N` to exit).
- Handles invalid user inputs gracefully.

## Prerequisites

- Python 3.x installed on your machine.

## How to Run

1. Clone or download this repository.
2. Open your terminal or command prompt and navigate to the project directory.
3. Run the Python script:

```bash
python dice_roller.py
